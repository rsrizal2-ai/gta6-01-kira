Porto Luna is an original open-world crime game set in a sun-soaked coastal city. Drive and explore eight-by-eight blocks of avenues, beach, boardwalk and hills; run five story jobs for Eddie Kwan, the fixer at Luna Garage; steal cars, dodge the Vulture crew and the Porto Luna PD's wanted system; and hunt down ten hidden moon charms. Built with three.js, fully offline, no build step.

## Run it

```sh
node serve.ts
# Open http://localhost:8080 in a desktop browser.
```
